# Менеджер задач

## Описание

Консольное приложение на Python для добавления, просмотра и завершения задач. Данные хранятся в `src/tasks.json` в формате JSON. Если файла нет, приложение начинает с пустого списка и создаёт файл при сохранении.

## Установка

Установите Python 3. Внешние зависимости не нужны: приложение использует стандартную библиотеку. Выполняйте команды из корня проекта. Если `python` отсутствует в PATH, укажите полный путь к интерпретатору.

## Использование

```shell
python src/tasks.py add "Купить хлеб"
python src/tasks.py list
python src/tasks.py done 1
```

В списке `[ ]` обозначает незавершённую задачу, `[x]` — завершённую. ID новой задачи равен максимальному существующему ID плюс один.

## Команды

| Команда | Действие |
|---------|----------|
| `add <title>` | Добавляет задачу. Пустое название или только пробелы не допускаются. |
| `list` | Показывает все задачи. Дополнительные аргументы не допускаются. |
| `done <id>` | Завершает задачу с указанным целочисленным ID. |

Успешные команды завершаются с кодом `0`. Неверные аргументы, неизвестная команда и отсутствующий ID приводят к коду `1`. Валидация названия выполняется в `add_task()`; CLI обрабатывает `ValueError` и выводит сообщение в stderr.

Проверка проекта:

```shell
python -m unittest discover tests
```
