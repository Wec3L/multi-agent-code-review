# Заметки: где агенты сделали не то

## 1. Ревьюер пропустил дублирование кода
**Что случилось:** Разработчик добавил проверку пустого названия задачи в двух местах: в add_task() и в main(). Ревьюер выдал вердикт OK и не заметил дублирования.

**Почему:** в инструкции Ревьюера было только общее "ищи проблемы читаемости", без конкретики.

**Что поменял в agents/reviewer.md (раздел Роль):**
Добавил строку: "Обязательно проверяй дублирование кода: если одна и та же проверка или логика написана в двух местах, это замечание типа "читаемость"."

## 2. Тестировщик не нашёл python
**Что случилось:** команда python не находилась, Тестировщик запускал Python по полному пути.

**Почему:** Codex был запущен до установки Python, и его терминал не видел обновлённый PATH.

**Что сделал:** перезапустил Codex после установки Python. Инструкцию менять не пришлось, это проблема окружения, а не агента.

## 3. Ограничение tools в Codex
В шапке агентов указаны tools (например, у Тестировщика только read, run), но Codex CLI не ограничивает инструменты жёстко по этому полю. Запрет работает только как текстовая инструкция в разделе "Запреты".
## 4. Проверка лимита возвратов (микро-задача 6)
Добавил намеренно сломанный тест (1 + 1 == 3). Разработчик не мог его починить, так как ему запрещено менять tests/. Конвейер вернул работу Разработчику 2 раза и остановился с пометкой "Тесты не прошли после 2 итераций". Бесконечного цикла нет, тест затем удалён.
