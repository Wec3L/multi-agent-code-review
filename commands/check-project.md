# /check-project

Цель проверки: $ARGUMENTS
(если цель пустая, проверяй весь проект в src/)

Выполни конвейер строго по docs/workflow.md.

1. Прочитай agents/conductor.md и выполни роль Дирижёра. Передай ему цель проверки. Сохрани его План.
2. Прочитай agents/developer.md и выполни роль Разработчика. Передай ему План Дирижёра.
3. Прочитай agents/tester.md и выполни роль Тестировщика. Передай ему список изменений Разработчика.
4. Если Итог Тестировщика FAIL: вернись к шагу 2 и передай Разработчику упавшие проверки. Максимум 2 возврата.
5. Прочитай agents/reviewer.md и выполни роль Ревьюера. Передай ему изменения, отчёт тестов и git diff.
6. Прочитай agents/documenter.md и выполни роль Документатора. Передай ему изменения Разработчика и вердикт Ревьюера.
7. Снова выполни роль Дирижёра: собери итоговую сводку из всех отчётов.

Правила:
- Вызывай агентов строго по очереди.
- Каждому агенту передавай вывод предыдущего, а не исходную задачу.
- Не переходи к следующему шагу, пока текущий не выдал ответ в своём формате.
- На каждом шаге соблюдай Запреты из файла агента.
- В самом начале вызови инструмент reset_run, чтобы очистить прошлый прогон.
- Поле summary в report_step всегда пиши на английском языке, коротко.
